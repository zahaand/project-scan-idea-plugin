# Implementation Plan: Model — Structured Data Contract for Project-Scan

**Branch**: `001-model-data-contract` | **Date**: 2026-06-12 | **Spec**: [spec.md](spec.md)  
**Input**: Feature specification from `specs/001-model-data-contract/spec.md`

## Summary

Create a `:model` Gradle submodule containing 15 plain Kotlin data classes and enums that define the `ProjectScanModel` root aggregate and its five sections (Stack, CodeStyle, Linters, Tests, Structure). This model is the stable, IntelliJ-Platform-free contract between the future `scan` producers and the `prompt`/`ui` consumers. Unit tests verify structural correctness, empty-state representability, and style-source priority ordering.

## Technical Context

**Language/Version**: Kotlin 2.2.20 / JDK 21 (JetBrains Runtime)  
**Primary Dependencies**: Kotlin stdlib (transitively via `org.jetbrains.kotlin.jvm` plugin); JUnit 5 (test only)  
**Storage**: N/A  
**Testing**: JUnit 5 (via `libs.junit` version catalog entry)  
**Target Platform**: IntelliJ IDEA 2025.3.5 — model submodule itself has NO platform dependency  
**Project Type**: IntelliJ IDEA plugin (Gradle, Kotlin DSL); `:model` is an isolated Kotlin library submodule  
**Performance Goals**: Test suite completes in < 5 seconds (SC-005)  
**Constraints**: No `org.jetbrains.intellij.platform` plugin or SDK on `:model` compile/runtime classpath (SC-004)  
**Scale/Scope**: 15 types, ~6 test classes, single Gradle submodule
